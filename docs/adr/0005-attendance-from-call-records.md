# Attendance from call records

Classlop reads Attendance from Graph call records with the application permission `CallRecords.Read.All`, taking a client-credentials token from the same "Classlop dev" registration and client secret that Teacher sign-in uses. `attendanceReports` fails on the demo tenant with `SDS_ErrorInvalidUser`, while call records work without a mailbox and name each signed-in Student with join and leave times (`docs/research/teams-fallback-smoke-test.md`). This is the one app-only permission beside the delegated ones; the Teacher's tenant grants it once with admin consent, which a teacher owning the tenant can give. The secret lives in `.env` locally and in Secrets Manager in prod, and is rotated by re-running `scripts/setup-demo-tenant.sh`. Lessons stay standalone meetings with the join link posted to the Class channel, since recurring events need mailboxes the demo tenant lacks; `attendanceReports` is not kept as a second source. A record appears about 27 minutes after a Lesson ends, so the first fetch runs at the scheduled end + 45 minutes, and a Lesson's Attendance is every record with its `joinWebUrl`, merged.
